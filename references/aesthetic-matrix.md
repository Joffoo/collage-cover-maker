# 现代混合拼贴美学底座与空间拓扑规范（Selman Hoşgör 体系）

## 艺术范式与美学底座

### 1. Selman Hoşgör 当代混合媒介画报编辑拼贴
以写实摄影照片（保留微观真实细节、眼神光与发丝）为现实生活锚点，将其形态化为带 4~6px 冲压模切纯白边（Die-cut Sticker）的实体贴纸。
对撞**即兴高饱和丙烯厚涂（Acrylic Smears）**、**黑色手绘马克笔涂鸦（Doodles）**与**Dymo 实体打标机黑白胶带标语**，展现当代画报幽默、敏锐与现代思辨张力。彻底淘汰 1930s 做旧牛皮纸、45° 半色调网点与纯色矢量压平。

### 2. Dymo 实体打标胶带排印（Typography as Label Tape Sticker）
主副标题文字在拼贴中不是浮空的虚拟数码字幕，而是用实体打标机冲压压印的硬质塑料/厚纸打标胶带：
1. **主标题胶带**：极粗纯白无衬线块面字，印在 #111111 纯黑胶带条上，以 -2.5°~-3° 动态微倾角横贯于胸前或画面下 1/3 处；
2. **副标题胶带**：鲜红（#E52521）或钴蓝（#0052FF）胶带条，以轻微反向倾角（+1°）形成视觉节奏交错；
3. **物性触感**：胶带边缘带有铡刀裁切口与立体微距投影（`box-shadow: 4px 8px 22px rgba(0, 0, 0, 0.35)`）。

### 3. 即兴高饱和丙烯笔刷与手绘涂鸦
1. **丙烯厚涂色块**：电光钴蓝（#0052FF）、荧光柠檬黄（#FFE600）与鲜品红（#FF2A85），带有飞白与油墨厚刷毛肌理，从人物脑后或身侧大开大合地动态倾斜扫出；
2. **手绘马克笔涂鸦**：黑色马克笔线条（脑波螺旋线、漫画闪电 ⚡、惊叹火花、手绘星号草图），将内心情绪与抽象思考以极具幽默感的漫画符号外化。

### 4. 纯净视觉红线（防杂质与防元话语铁律）
1. **彻底铲除全部多余小字与标签**：严禁在图内添加 `VOL. XXX`、`ARCHIVE NO.`、假期号贴纸或装饰性印章；
2. **拒绝陈旧做旧**：严禁使用做旧茶渍圈、水渍、破旧折痕或老式活字印刷；
3. **现代画廊展陈呼吸感**：底板采用开阔纯净的现代画廊展陈暖白（#F7F5F0），留白舒展。

## 四画幅排版底座与视窗安全区断言

### 1. 微信公众号封面（超宽画幅 2.35:1，2115×900）
- **物理规格**：`2115×900`（比例 `2.35:1`）；
- **中央正方形缩略安全区**：微信消息列表抓取正中央 `900×900` 区域（`607.5px ~ 1507.5px`）；
- **硬指标断言**：主副标题打标胶带必须收敛在 `650px ~ 1465px` 范围内，核心面部神态与道具接触点在 1:1 视窗内自洽平衡。

### 2. 标准宽屏与演示封面（经典画幅 16:9，1920×1080）
- **物理规格**：`1920×1080`（比例 `16:9`）；
- **适用场景**：B站视频封面、网站落地页、大会演讲 PPT 题图、博客题图。

### 3. 小红书封面图文（垂直竖屏 3:4，1440×1920）
- **物理规格**：`1440×1920`（比例 `3:4`）；
- **系统避让区**：顶部避让 80px 状态栏，底部避让 140px 系统交互栏，右上角避让 180×180px 悬浮图标；
- **排版结构**：顶部极客标签，人物与丙烯笔刷在 `400px ~ 1300px` 垂直延展，Dymo 胶带主标题稳固落在 `1340px ~ 1550px`。

### 4. 微信 1:1 正方形缩略视窗（1:1，900×900）
- **物理规格**：`900×900`（比例 `1:1`）；
- **生成方式**：由 2.35:1（2115×900）正中央精确裁切（Crop `x: 607, y: 0, w: 900, h: 900`）。
